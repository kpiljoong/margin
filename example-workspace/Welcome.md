# Welcome to Margin
This workspace is just a folder of Markdown files. Open it in any editor, sync it with git, grep it — nothing is locked in.   

##How to try the agent loop
1. Open [[Launch plan]] and press ⌘K (Ctrl+K).
2. Pick a recipe such as *Tidy* or *Summarize* and run it.
3. Review the proposed changes hunk by hunk, then apply only what you like.

* Everything the agent does happens on a **staged copy**.
* Notes marked `private: true` are never shared — see [[2026-09-24]].
+ Undo any applied run from its review tab.
